# Bid Arena 使用指南

Bid Arena 是多人实时拍卖间。你可以使用虚拟积分出价、查看领先情况和成交结果，查看自己的钱包与资金流水。**积分不是真实货币，不涉及充值、支付或提现。**

## 打开与登录

由维护者启动本地演示环境后，访问 [拍卖间](http://127.0.0.1:5173)。该地址只能在运行项目的电脑使用；无法打开时请联系维护者。当前没有公开注册服务。

输入邮箱和密码，点击「登录」。以下是**公开开发演示账号，仅限本地演示，禁止用于生产环境**：

| 身份 | 邮箱 | 公开演示密码 |
|---|---|---|
| 管理员 | admin@example.com | Admin123456! |
| 真人 A | bidder_a@example.com | Test123456! |
| 真人 B | bidder_b@example.com | Test123456! |

多人体验时使用不同浏览器或隔离会话分别登录。演示积分会随使用变化，不保证每次登录都有初始余额。管理员会看到管理工具，普通账号用于参与竞拍。

点击左侧「退出登录」结束会话。如提示服务端吊销未确认，恢复网络后联系管理员撤销会话。账号无效时核对邮箱和密码；会话过期或被撤销时重新登录；访问被拒绝时确认权限。当前没有密码找回页面，请联系维护者。

## 认识页面

- **左侧**：角色及用户 ID、钱包、拍卖列表。「刷新列表」重新获取拍卖；选中拍品有标记，列表可以独立滚动。
- **中央**：名称、最高价、领先者 ID、剩余时间、延时次数、参与人数和截止时间；下方是竞拍操作、参与者和最近出价。
- **右侧**：「出价历史」查看所选拍卖记录；「资金流水」查看自己的资金变化。管理员另有「创建拍卖」和「Agent 管理」。右侧可独立滚动。
- **同步提示**：「已同步」表示最近同步成功；「连接中断，正在重试」或钱包「同步中」表示数据可能过时。等待恢复或刷新页面，再确认价格、钱包及成交结果。左侧连接装饰文字不保证请求成功，应以房间和钱包的实际同步提示为准。

## 参与拍卖

1. 在左侧选择拍品，核对状态、价格、领先者、剩余时间和延时次数。
2. 点击「加入拍卖」。草稿或进行中允许加入，结束或取消后不能加入。
3. 等管理员开始拍卖。只有 RUNNING 状态接受出价。
4. 输入整数「出价积分」，点击「提交出价」。起拍价 100，最小加价 10，因此第一次最低 **110**；之后至少为当前最高价加 10。
5. 查看反馈和最新房间信息。「出价已接受」只确认这一次报价；「你目前领先」只是暂时领先；其他人超过你后，你不再领先。
6. 等待结算，查看成交结果的赢家 ID 和成交价。**只有 FINISHED 的成交结果能确定赢家；当前领先或倒计时归零都不等于已经获胜。**

最后 5 秒内的合法出价，将原截止时间延长 10 秒，每场最多 3 次。服务端接收时间必须早于截止时间，恰好到点也算迟到。出价过低、未加入、余额不足或拍卖结束会拒绝；失败不会新增冻结或扣款。

| 状态 | 含义 |
|---|---|
| DRAFT | 待开始，不倒计时，可加入 |
| RUNNING | 进行中，可以出价 |
| SETTLING | 正在结算，不能出价或取消 |
| FINISHED | 已结束，以成交结果确认赢家；无人出价无赢家、不扣款 |
| CANCELLED | 已取消，无赢家，冻结释放 |

系统不支持离线出价。断网时不要连续提交，恢复后重新同步。结果不明确时先核对历史和钱包，避免把新报价误当作原请求重试。

## 钱包与资金流水

**可用积分 = 总余额 − 冻结金额。** 总余额是尚未实际消费的积分；冻结是领先报价占用的额度，可能来自多场拍卖。可用积分才是还能投入竞拍的额度。

| 类型 | 含义 |
|---|---|
| 初始积分 INITIAL_CREDIT | 初始化发放积分 |
| 冻结 FREEZE | 占用可用额度，总余额不变，不是扣款 |
| 释放 RELEASE | 解除冻结，可用积分恢复，总余额不增加 |
| 成交扣款 CAPTURE | 最终赢家支付成交价，同时解除对应冻结 |

例如，假设总余额 1000、没有其他冻结。出价 110 领先后，总余额仍 1000、冻结 110、可用 890。同场加到 120，只再冻结 10，可用变为 880。被他人超过后，冻结释放，可用恢复 1000；若最终以 120 获胜，总余额变为 880、冻结归零、可用 880。取消也释放冻结。

右侧「资金流水」分别展示总余额变化与冻结变化，并显示关联拍卖。只有最终赢家支付成交价；其他人的冻结释放，不会获得额外积分。

## 管理员操作

1. 点击「创建拍卖」，填写名称、时长（默认 180 秒），点击「创建 DRAFT 拍品」。新拍卖不自动倒计时。
2. 确认中央选中拍品，点击「开始拍卖」才开始倒计时。
3. DRAFT 或 RUNNING 可点击「取消拍卖」，冻结会释放。SETTLING 和终态不能取消。
4. 在中央查看参与者，在右侧查看出价历史，结束后核对成交结果。页面不提供直接修改余额或历史资金流水的功能。
5. 使用「Agent」标签页选择策略和预算，点击「创建并启动 Agent」，见下节。

## 自动竞拍 Agent 使用教程

独立 Agent 是自动竞拍账号与后台服务，不是聊天助手。真人点击出价，Agent 则按预算自主判断；它不保证获胜，也不能创建或开始拍卖。关闭浏览器不会停止 Agent。

### 启用服务

在运行项目的电脑安装并启动 Docker Desktop 和 Node.js 22，在项目根目录运行。已有 `.env` 会保留，已有积分不会重新发放。

```powershell
node scripts/setup-env.mjs
node scripts/setup-agent.mjs
docker compose --profile agents config --quiet
docker compose --profile agents up -d --build
docker compose --profile agents ps
```

打开 http://127.0.0.1:5173，以管理员登录。数据库仍映射到本机 3307，不占用现有 MySQL 3306。首次启动需要下载镜像。服务应为 healthy，启动失败时检查 `docker compose logs --tail=100 agent-worker backend`。

### 创建并启动 Agent

1. 从左侧选择目标拍卖，打开右侧「Agent」标签页。输入任务名称，选择均衡型、保守型或仅监控策略，并设置最高出价和最多出价次数。
2. 点击「创建并启动 Agent」。系统会自动建立专用身份、设置初始积分并签发本场授权；无需填写邮箱或密码、查用户 ID、复制 Token 或运行命令行。
3. DRAFT 拍卖中的 Agent 会进入等待状态。管理员点击中央「开始拍卖」后，后台 Worker 才会开始监控；Agent 不会自行开始拍卖。
4. 在任务状态中查看当前价格、领先者、预算占用、出价次数、最近决策和错误。仅监控策略不会提交报价；均衡型和保守型会在限制内自动判断是否跟价。
5. Agent 已领先时不会自行抬价。最高出价是上限，不是额外积分；到达限额后 Agent 继续观察但不再出价。成交与扣款以服务端最终结果为准。

### 暂停、停止与故障处理

- 「暂停」暂时阻止新出价；「恢复运行」继续任务。「停止 Agent」结束该任务的新出价处理；已有请求结果未确定时会先等待确认，已接受的报价不会撤销。
- 在「授权与任务详情」中点击「撤销 Token」会使凭证失效并阻止任务继续运行。关闭浏览器不会停止后台 Agent，也不会自动撤销授权。
- 最高出价不能超过 Agent 专用账号的初始 1000 积分。达到最高出价或次数上限后，Agent 会继续监控但不再出价。
- 如果运行状态未更新，点击「刷新运行状态」；问题持续时联系系统维护者检查服务。

维护者可单独管理 Worker，不需要终端持续运行竞拍循环：

```powershell
docker compose --profile agents stop agent-worker
docker compose --profile agents start agent-worker
docker compose --profile agents restart agent-worker
docker compose --profile agents logs --tail=100 agent-worker
```

停止 Worker 进程会中断所有任务处理，恢复后按租约和原请求继续确认。阻止某任务的新报价应先在页面停止/吊销并等待确认。不要删除私有凭证卷或随意更换加密密钥。旧 `scripts/auction-agent.mjs` 仅是手动示例，不是服务入口。

### 独立服务器与可用范围

提供 [独立 Worker 模板](deploy/compose.agent.yaml)。维护者配置 HTTPS 后端、专用协调凭据和加密密钥，并建立后端到 Worker 的私有 TLS 通道后运行：

```powershell
docker compose --env-file .env -f deploy/compose.agent.yaml config --quiet
docker compose --env-file .env -f deploy/compose.agent.yaml up -d --build
```

Worker 不连接数据库，不持有管理员会话。远程须另配网络白名单、证书与私有通道，不能把本机明文接收端暴露到公网；详情见 [部署维护说明](docs/AGENT_SERVICE_OPERATIONS.md)，验证范围见 [Agent 服务报告](AGENT_SERVICE_REPORT.md)。

**当前可用方式是本机 Compose 与受控网络，没有公开 Agent 服务上线。** MySQL 镜像安全门禁尚未通过，域名、服务器、证书等外部资源未具备，不能据此开放开发环境。

## 常见问题

**为什么不能加入或出价？** 检查状态、同步提示，先加入再出价。只有进行中接受报价，金额需足够、可用积分需充足。服务端已到期时，即使本地仍显示时间也会拒绝。

**为什么出价成功却没有赢？** 成功只表示当次报价合法，别人仍可超过你。最终赢家只看 FINISHED 成交结果。

**为什么冻结释放后总余额没增加？** 冻结只是占用额度，释放只恢复可用积分。有其他拍卖冻结时，可用积分不一定全部恢复。

**为什么一直同步中？** 检查网络及服务是否运行，等待恢复；仍不成功则刷新页面，必要时重新登录并选中拍品获取最新状态。不要把旧画面当成最终事实。

**看不到刚创建的拍品？** 点击「刷新列表」。出价历史属于当前选中拍卖，钱包和流水属于自己，范围不同。

**结束后还能加价吗？** 不能。结算中或终态不接受报价，需管理员创建新的拍卖。

## 安全与使用范围

不要公开分享个人密码和 Agent Token。生产账号由维护者安全配置，不能使用公开演示凭据。当前仅用于本机演示和受控环境，**生产安全门禁尚未通过，不可公开上线、开放公网注册或用于真实交易**。页面可用不代表公网证书、备份和告警等运营保障已完备。
