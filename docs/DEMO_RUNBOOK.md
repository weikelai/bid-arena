# 3–5分钟演示流程

准备：Compose三服务healthy，保留原演示DRAFT；为演示新建短时拍卖（例如60秒），三个独立浏览器会话。不要显示Token、环境变量或私有配置。完整自动化在隔离数据库运行，不把模拟写到原有业务库。

0:00–0:40 管理员登录，展示DRAFT无倒计时，开始新拍卖。
0:40–1:20 真人A/B加入，110/120交替出价，展示新领先冻结、旧领先释放、同人差额。
1:20–2:00 在隔离测试终端运行20人模拟，展示seed42、并发重复请求断言；浏览器短暂离线再连接，观察恢复价格与seq。
2:00–3:00 管理员创建Agent、签发Token，暂停录制或遮挡后交给安全环境中的Agent，隐藏Token后恢复录制；运行auction-agent.mjs或展示隔离模拟中真实Agent出价。
3:00–4:00 截止前五秒出价，展示截止加十秒和三次上限，自动结算后展示赢家/价格、钱包与流水；终端展示SQL资金对账测试结论。
4:00–4:30 展示OpenAPI、真实测试摘要、Git提交与未验证事项。
